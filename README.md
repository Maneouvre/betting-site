# MatchMate demo

MatchMate is a PHP, MySQL, HTML, CSS, and browser-JavaScript prototype for football peer bets and Konami eFootball 1v1 matches.

## Run locally with XAMPP

1. Start **MySQL** in the XAMPP Control Panel.
2. In phpMyAdmin, import `schema.sql`. It creates the `matchmate` database and tables.
3. Copy the project folder into `C:\xampp\htdocs\matchmate`, or start PHP's built-in server from this folder:

   ```powershell
   php -S 127.0.0.1:8000
   ```

4. Visit `http://127.0.0.1:8000`.
5. Register a player account. The generated account number is used with the password to sign in.
6. To enable the admin dashboard, promote a registered account in phpMyAdmin:

   ```sql
   UPDATE users SET role = 'admin' WHERE account_number = 'MM-2026-12345';
   ```

   Sign out and sign back in to refresh the account role.

The default database settings are for a local XAMPP installation (`127.0.0.1`, database `matchmate`, user `root`, blank password). Set `DB_HOST`, `DB_NAME`, `DB_USER`, and `DB_PASS` in the PHP server environment when using different local database settings. Never deploy the local defaults to a public server.

## Demo limits

- Fixtures are illustrative sample data generated by the PHP endpoint, not a live football schedule.
- Matchmaking works between accounts using the same installation and database. Stakes are integer KES amounts of at least KES 50. Football matches require the same fixture, equal stakes, and different predictions; eFootball matches require equal stakes.
- Football bets close 30 minutes before kick-off. eFootball players have a five-minute window to submit their M-Pesa transaction reference after a match is found.
- Each player submits a payment reference. An admin must check the reference in M-Pesa and approve it before the player can submit an eFootball room code. The prototype does not initiate, verify, or reconcile M-Pesa transfers.
- Each eFootball round is one game. Both players submit their result once; compatible reports automatically identify the agreed winner, while conflicting reports are resolved by an admin. Room codes are not a Konami result feed.
- The same players can start another separate round after the previous result is recorded. A new stake and payment approval are required; each round has its own 2× payout. The player dashboard totals stakes, pending payouts, and payouts manually marked sent.
- A winner's payout is twice their matched stake with no transaction or manager fee deducted. M-Pesa transfer fees are not yet configured; verify the current Safaricom tariff before displaying any fee estimate. Transfers and the "mark sent" action are manual.
- WhatsApp and SMS links open a prefilled message; the site does not send messages.
- This prototype is not a regulated betting service. It does not provide live fixtures, payment processing, independent result verification, or production-ready fraud controls. Use secure hosting, HTTPS, restricted database credentials, regulatory review, payment-provider integration, and verified result feeds before any real-money use.
